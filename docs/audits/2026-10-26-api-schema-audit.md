## Main conclusion

Reuse the settled rows, repositories, scoped RBAC and encrypted generation slots. The main bloat is parallel representations of the same decision: old account roles beside scoped assignments; provider-name singleton secrets beside credential instances; global runtime routing documents beside typed project settings; and account-owned trace readers beside project readers. Wrapping both representations in more facades would retain the problem.

The target is typed OOP: cohesive objects and focused repository/service/adapter contracts owning live principal verification, scoped permission decisions, atomic local mutation, credential generation/tombstone transitions, typed settings resolution and project-scoped reads. Shared base classes/generics are appropriate for real common behavior. Avoid a resource-service hierarchy that mixes unrelated responsibilities, an unrestricted settings copier or a second scheduler/persistence authority. The main report's sections 4.6–4.7 clarify the intended typed object boundaries.

Static inventory provides scale, not a deletion quota: 101 Python source files / 43,591 physical lines; 218 Python test files / 91,516 physical lines. Comments and blanks are included. Examples: `routers/control.py` 1,332 lines, `persistence/storage.py` 1,297, `services/parallel_oauth.py` 1,197, `models/projects.py` 1,166, `services/credentials.py` 945 and `services/settings.py` 635. Size alone does not establish unnecessary code.

**Protected criteria/history.** A1 AC1–3, AC7; D1 AC5; P02/TASK-000019 AC1, AC3–6. Existing `require_admin` and `require_control_reader` already call live scoped authorization (`routers/auth.py:335`); their names do not establish a role-based bypass.

### API-02 — P1 / A1→A2→A3: make one verifier authoritative for machine credentials on every execution

**Evidence.** `src/polyweb/persistence/api_keys.py:146` (`ProjectApiKeyRepository`) already supplies create, project-scoped get/list/revoke, global-prefix lookup and monotonic use recording. `src/polyweb/mcp/auth.py:62` (`LocalTokenVerifier.verify_token`) delegates to human `AuthService`; `:92` (`require_mcp_user`) rechecks a human token per call, but actual server composition calls `optional_mcp_user` via `src/polyweb/mcp/server.py:942`. `optional_mcp_user` (`mcp/auth.py:120`) returns the ASGI principal when request context exists. `src/polyweb/services/execution_scope.py:57` accepts only `UserPrincipal | None` and unconditionally converts it with `human_principal` at `:77`. **Protected criteria/history.** A1 AC4–8; A2 AC1–2, AC7; A3 AC1–2. Existing per-call human revocation behavior is a guarantee to translate, not an obsolete test to discard.

**Before removal.** Keep repository tests such as `tests/integration/persistence/test_api_keys.py:82` (null expiry), `:111` (digest-only storage), `:166` (no repository commit), and `:182` (lookup establishes the key's own project). Do not infer these behaviors from D1 repository presence.

### API-03 — P2 / A1,A4,A5: consolidate SQLite write mechanics, retaining domain-specific failure decisions

**Evidence.** `ProjectService._write` at `src/polyweb/services/projects.py:643`, `SettingsService._write` at `services/settings.py:588` and `CredentialService._write` at `services/credentials.py:880` repeat new session → `BEGIN IMMEDIATE` → operation → commit, rollback, lock-message classification and exponential retries. Services own permission checks, last-admin validation, CAS conflicts and atomic audit appends. Retried closures must contain no vendor network calls or externally visible one-time delivery; retrying a provider call or OAuth exchange is a different decision.

**Protected criteria/history.** A1 AC3, AC8; A4 AC1–3; A5 AC1–2. P02 AC4, P03 AC4 and P08 AC5 protect serialized admin checks, one-winner revisions and metadata/ciphertext atomicity.

**Before removal.** Run real temporary-SQLite independent-connection races, lock exhaustion, cancellation rollback, constraint failure and secret-slot failure. Keep `tests/integration/services/test_settings.py:587` (concurrent writers) and `tests/integration/services/test_credentials.py:533` / `:828` (concurrent rotation / slot rollback). Test the helper's mechanics once; retain domain outcomes in each service suite. Retries must remain bounded and must not be added unconditionally to the latency-critical execution path.
