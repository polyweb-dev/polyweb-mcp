Polyweb gives your AI agent and your own code two operations, `search` and `fetch`, backed by the search providers you choose. You run it yourself with Docker, add your provider keys once, and hand out project API keys.

## How it fits together

A **project** holds its own providers, members, and API keys. You store provider keys in an encrypted vault, group them into key pools, and bind a pool to each project. Calls then pick a provider for you, and every call is recorded as a trace.

Start with [Quick start](/quick-start/), then run [your first search](/guides/first-search/). Read [Projects and roles](/concepts/projects-and-roles/) when you want the full picture.
